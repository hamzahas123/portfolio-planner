# Portfolio Scenario Planner

An interactive what-if tool for a technology project portfolio. Leaders can test budget, cost, and timing assumptions and immediately see the impact on the capital plan.

**Live demo:** https://hamzahas123.github.io/portfolio-planner/

## What it does
- **Budget cap:** funds projects in priority order and shows which ones fall below the cap line
- **Cost change and contingency:** applies vendor rate, inflation, or reserve assumptions to every project
- **Delays:** pushes Priority 3 projects (or any single project) out by quarters and shows the spend deferred past the plan window
- **Include/exclude:** removes projects from the scenario
- **Outputs:** KPI tiles, quarterly baseline vs. scenario spend, spend by category, a plain-language summary, and CSV export

## How it was built
Built with AI-assisted development (Claude) as a single HTML/CSS/JavaScript page using Chart.js, and published with GitHub Pages.

All projects and figures are fictional sample data.
